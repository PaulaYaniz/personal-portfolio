## Overview

Developed an interactive ArcGIS dashboard mapping 50+ thrift stores across Madrid to study market concentration patterns and consumer behavior. The project combines geospatial analytics with thoughtful UI design to improve accessibility and user engagement.

## Key Features

- **Interactive Mapping**: Comprehensive mapping of 50+ thrift stores across Madrid
- **Geospatial Analytics**: Analysis of market concentration and behavior patterns
- **UX Design**: Designed navigation flow and UI elements to improve accessibility
- **Data Visualization**: Clear presentation of complex geospatial data for various user types

## Technologies Used

- ArcGIS
- Web Mapping
- Data Visualization
- UI/UX Design
- Geospatial Analytics

## Project Status

May 2025 - Present (Ongoing)

## Impact

The directory serves as both a practical tool for Madrid residents seeking sustainable shopping options and a research platform for understanding thrift store distribution patterns. The accessible design ensures users of all technical levels can benefit from the geospatial insights.

## Future Development

Ongoing work includes expanding the database, adding user reviews and ratings, and incorporating additional analytics on sustainability impact and shopping behavior trends.
