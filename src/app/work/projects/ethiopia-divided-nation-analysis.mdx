## Overview

Developed an ArcGIS story map analyzing armed conflict and displacement patterns in Ethiopia. The project examines the geographic dimensions of the humanitarian crisis, providing insights into conflict zones, displacement patterns, and affected populations.

## Analysis Focus

- **Conflict Mapping**: Spatial analysis of armed conflict patterns and intensity
- **Displacement Patterns**: Tracking and visualization of population displacement
- **Humanitarian Impact**: Assessment of crisis impacts on different regions and communities
- **Data Synthesis**: Integration of multiple data sources for comprehensive analysis

## Technologies Used

- ArcGIS StoryMaps
- Geospatial Analysis
- Conflict Data Analysis
- Data Visualization
- GIS Mapping

## Project Date

November 2024

## Methodology

The analysis synthesized data from multiple humanitarian and conflict databases, applying geospatial analysis techniques to identify patterns and trends. The story map format enables both detailed analysis and accessible communication of findings.

## Significance

This project demonstrates the power of geospatial analysis in understanding complex humanitarian crises. The visualizations and analysis provide valuable context for policymakers, humanitarian organizations, and researchers working on conflict resolution and humanitarian response.
